# mobile-device-earthquake-fidelity
Shaking-table data and analysis code for evaluating mobile-device accelerometer fidelity under earthquake excitation.

## Experimental Data

The experimental dataset is hosted separately due to its file size.

Data access:
[Data](https://drive.google.com/drive/folders/1fdASxP2cCs_5APzoVngImvpqp45xwOX8?usp=drive_link)

The shared dataset contains:
- mobile-device acceleration recordings,
- measured shaking-table reference recordings,
- prepared shaking-table input files, and
- supporting experimental metadata.

The measured shaking-table acceleration files are the reference signals used
for the analyses reported in the paper.

To reproduce the analyses, download and extract the dataset and place the
contents in the `data/` directory of this repository.
